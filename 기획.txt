================================================================================
                         🎉 GGWATING - 과팅 도우미 사이트 기획서 🎉
================================================================================

📌 프로젝트 개요
--------------------------------------------------------------------------------
- 프로젝트명: GGWATING (과팅)
- 목적: 오프라인 과팅을 더욱 흥미롭게 만들어주는 진행자/도우미 사이트
- 특징: 검색 유입 X, 오프라인 현장에서 QR코드로 접속하는 방식

📌 핵심 철학
--------------------------------------------------------------------------------
- 과팅 참여자들의 목표는 "새로운 사람을 만나는 것"
- 사이트는 보조 역할, 이벤트에 과몰입 방지
- 자연스러운 분위기 조성이 최우선

================================================================================
                                 주요 기능
================================================================================

🔷 1. 방 참여 시스템
--------------------------------------------------------------------------------
  - 오프라인 가게의 실제 방번호 입력
  - QR 코드 생성 → 휴대폰 스캔으로 참여
  - 참여 시 입력: 이름 + 비밀번호 4자리
  - 6명 참여 완료 시 과팅 시작

🔷 2. 자기소개 시간
--------------------------------------------------------------------------------
  - 자유로운 분위기에서 인사
  - 10분 후 다음 단계 이벤트 팝업
  - [진행] / [취소] 버튼으로 선택 가능

🔷 3. 첫인상 투표 (익명)
--------------------------------------------------------------------------------
  - 각자 휴대폰에서 마음에 드는 이성 투표
  - 매칭된 커플이 있으면 커플 수만 공개
  - (보류) 본인 득표수 표시 - 분위기 루즈해질 수 있음

🔷 4. 최종 선택
--------------------------------------------------------------------------------
  - 과팅 마무리 단계에서 최종 선택 진행
  - 상세 기능 추후 기획

🔷 5. 게임 추천
--------------------------------------------------------------------------------
  ✓ 귓속말 게임
  ✓ MBTI 맞추기
  ✓ 이상형 말하기
  ✓ 연애 밸런스 게임
  ✓ 손병호 게임

================================================================================
                              추가 아이디어
================================================================================

💡 소리 인식 이벤트
--------------------------------------------------------------------------------
  - 분위기가 조용해지면 자동으로 이벤트 팝업
  - 어색한 순간 해소용

💡 포토 앨범 기능
--------------------------------------------------------------------------------
  - 중간중간 사진 촬영 유도
  - 과팅 종료 후 추억 콘텐츠 제공
